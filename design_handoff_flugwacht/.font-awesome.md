# Font Awesome Configuration

## Integration

- **Method:** Web-Fonts-Kit (im FA-Konto umgestellt) — <i>-Klassen rendern als Font, kein DOM-Konflikt mit React. Kit-Script im <helmet> jeder Datei.
- **Version:** 7.x (Kit liefert v7.3.1)
- **License:** Pro (Kit ohne Domain-Beschränkung)
- **Kit-URL:** https://kit.fontawesome.com/85fa8e3a78.js

## Defaults

- **Style:** regular
- **Family:** classic

## Icons in use

map, list, sliders, layer-group, location-arrow, calendar, plus, chevron-right

## Conventions

- Mockups (HTML): `<i class="fa-regular fa-NAME" style="font-size:...;color:..."></i>`; Kit-Script im <helmet>. fa-regular-icons.json bleibt als Offline-Fallback (Inline-SVG-Pfade).
- Flutter-App: font_awesome_flutter; Pro-Setup mit vorhandener Lizenz über FA CLI / Claude Code.
